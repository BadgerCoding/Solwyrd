# Solwyrd Path Directory

This folder is the workspace file map. Each entry shows a file name and a short description; paths are relative to the `Solwyrd` main folder.

## Main folders

- `[app]_solwyrd/` — Godot app project (quiz RPG and app interface).
- `[game]_solwyrd/` — Godot game project (Sir Vey, enemies, world scenes, and art assets).
- `[web]_solwyrd/` — HTML web pages.
- `Godot_Linux_Launcher/` — Godot Linux executable.
- `Path/` — this directory map.

## File catalog

Catalogued 2097 files across the four project folders.
Godot `.godot/` directories are generated editor/import/shader caches, so their individual cache files are not expanded below; they can be recreated by Godot.
